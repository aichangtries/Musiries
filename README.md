# Musiries - Music Around the World 🎵

A beautiful, interactive website that showcases music from different countries around the globe. Explore diverse musical traditions, genres, and famous artists from every continent.

## Features

- **Interactive Filtering**: Browse music by region (Asia, Europe, Africa, Americas, Oceania)
- **16 Countries Featured**: Discover music from Brazil, India, Jamaica, Spain, Mali, Ireland, Argentina, Japan, Cuba, South Africa, Greece, Australia, Egypt, France, Mexico, and South Korea
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Beautiful UI**: Modern gradient design with smooth animations
- **Rich Content**: Learn about genres, traditions, and famous artists from each country

## How to Use

Simply open `index.html` in your web browser to explore the world of music. Use the filter buttons to view music from specific regions, or browse all countries at once.

## Technologies Used

- HTML5
- CSS3 (with modern features like Grid, Flexbox, and Animations)
- Vanilla JavaScript (no dependencies required)

## Countries & Genres Included

- **Americas**: Brazil (Samba/Bossa Nova), Jamaica (Reggae), Argentina (Tango), Cuba (Son/Salsa), Mexico (Mariachi)
- **Asia**: India (Classical/Bollywood), Japan (J-Pop/Traditional), South Korea (K-Pop)
- **Europe**: Spain (Flamenco), Ireland (Celtic/Folk), Greece (Rebetiko), France (Chanson)
- **Africa**: Mali (Afro-pop/Blues), South Africa (Afro-jazz/Kwaito), Egypt (Classical Arabic)
- **Oceania**: Australia (Aboriginal/Rock)

Enjoy your musical journey around the world! 🌍🎶
